# Контроль мотивації Ласки

Розділ меню доступний у Ласці backend-ролям `admin` і `manager`. Перевіряється початкова роль, а не нормалізована UI-роль, яка прирівнює `brand_manager` до адміністратора. Сервер незалежно перевіряє ці ж права.

Окремі компоненти: `MotivationPage`, `MotivationOverview`, `MotivationComparison`, `MotivationRecords`, `MotivationEditor`, `MotivationSettings`; запити та мутації — в `useMotivation`, API — `src/api/motivation.ts`. Стилі ізольовані через CSS Modules. Спільні кольори SODA оголошено як `--soda-*` у `index.css`; поля успадковують чинні `--field-*`. Нових глобальних стилів для button/table/heading немає.

Виконання — середнє відсотків `min(100, факт / ціль × 100)` підтверджених записів. Відсутні значення не враховуються і позначаються «—». Дебіторка: факт/ціль означають позитивний показник своєчасності оплат, сума боргу зберігається окремо. Критична прострочка — наступний день після дати накладної + індивідуальний строк + буфер, лише якщо борг >0. Нуль і переплата критичної прострочки не створюють. Штрафів немає.

Є порівняння 10 агентів, маршрутів, поточного й попереднього періодів 3–6 місяців. Щоденний/щотижневий моніторинг використовує всі календарні дні/тижні діапазону, включаючи пропуски. Тиждень починається в понеділок. Дата за замовчуванням і час аудиту — Europe/Kyiv.

Імпорт JSON: масив записів за шаблоном додається до наявних результатів з новими ID; повний експорт `{agents, records, budget, buffer}` замінює стан після натискання «Застосувати імпорт». Попередні успішні збереження доступні з журналу як знімки. Файл до 7 МБ; загальний стан до 7,5 МБ. Підтримується експорт попередньої панелі Sites. Підтвердження і всю структуру остаточно перевіряє backend, атомарно. Невдалий імпорт не замінює поточні результати.

Запити використовують наявний `VITE_API_URL`, Bearer JWT і `x-tenant-id: laska`. Зберігання результатів — лише на backend. Конфлікт ревізії не перезаписує дані, помилка відображається в картці/імпорті; кнопка «Оновити дані» завантажує актуальний стан.

Короткий звіт формується за поточними фільтрами, показує нестачу підтверджень і три наступні кроки. Тестовий бюджет 15000 грн та 25% на напрям не є погодженими нарахуваннями; автоматичної відомості виплат немає.

Перевірка:

```sh
npm run build
node --test test/motivation.test.cjs
npx eslint src/components/MotivationPage src/types/motivation.ts src/api/motivation.ts src/api/client.ts src/App.tsx src/components/HomePage/HomePage.tsx
```

Спочатку випускається backend із `/api/motivation`, потім цей frontend. Дані Sites не переносяться без імпорту. Візуальний QA використовував окремий тимчасовий локальний стенд із синтетичними даними, який не входить у production.
