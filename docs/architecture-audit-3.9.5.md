## Підтверджені точки для рефакторингу

1. **Великі компоненти фронтенду:** `src/components/PlanTargetsPage/PlanTargetsPage.tsx` (~42 КБ), `SalesByDaysPage.tsx` (~30 КБ), `InfoBoardPage.tsx` (~28 КБ), `RouteHistoryPage.tsx` (~27 КБ), `ActiveCustomerBase.tsx` (~27 КБ). Розбивати на підкомпоненти та хуки тільки після фіксації поведінки тестами.
2. **Великі моделі бекенду:** `src/models/laskaSalesModel.js` (~33 КБ), `olgatorgSalesModel.js` (~20 КБ), `olgatorgSalesHistoryModel.js` (~19 КБ). Відділити побудову SQL, доступ до БД та нормалізацію результатів без зміни API.
3. **`src/App.tsx`** (~23 КБ) координує авторизацію, доступи та навігацію. Розділити конфігурацію маршрутів/меню й перевірку ролей, залишивши один авторитетний набір правил.
4. **Підтримка коду:** у frontend вже є `knip.json` і залежність `knip`, але в `package.json` немає скрипту для регулярного аудиту. Встановити базову перевірку після аналізу звіту Knip, щоб не видалити динамічні імпорти, PWA-ресурси та файли тестів.
5. **Документація:** `README.md` описує стару модель ролей (admin/supervisor/agent), хоча актуальний код підтримує також manager/brand_manager. Оновити документацію після перевірки обох шарів авторизації.
6. **PWA та офлайн:** зміни service worker не повинні видаляти IndexedDB або примусово перезавантажувати екран із незавершеною роботою. Перевірити оновлення в офлайні та після відновлення мережі.

## Порядок робіт

1. Запустити на однакових ревізіях `npm ci`, `npm run build`, `npm run lint`, наявні тести і Knip; зберегти початкові результати.
2. Побудувати граф імпортів і список кандидатів на видалення. **Не видаляти** файли тільки через відсутність статичних імпортів (lazy import, manifest, серверні маршрути, cron, завантаження з Google Drive).
3. Винести конфігурацію навігації/ролей та покрити матрицю доступів тестами, зокрема заборону дебіторки для brand_manager.
4. Рефакторити по одному модулю в окремих PR; порівнювати API-відповіді, Excel-експорт і поведінку на мобільних.
5. Перед злиттям: перевірити імпорт LASKA/OLGATORG, Cloudinary, Neon, фотозвіти з геолокацією, PWA та кеш офлайн. Деплой тільки після зелених перевірок.
